# 订阅提交与列表刷新

## Emby 用户与订阅归属

管理员可继续使用全部页面；Emby 普通用户登录后仅开放推荐、发现、媒体详情和电影/电视剧订阅页面。普通用户创建订阅时按系统默认规则执行，只能查看、启停或取消自己的订阅；管理员在订阅列表中可以查看和管理全部用户的订阅，卡片显示订阅人，并支持按用户名筛选。

「系统 -> 用户管理」中的 `EmbyUserManager` 插件支持 Emby 账号增删改查、密码与媒体库权限管理，以及 MoviePilot 登录准入控制。白名单模式仅允许名单内用户登录，黑名单模式仅拦截名单内用户，全部模式不读取名单；名单不影响 Emby 本身的媒体库权限。

新增订阅请求发出后，切换页面不会中断提交。前端收到后端最终结果后再提示成功或失败，真实的业务错误和网络错误仍会显示。

如果请求完成前已离开原页面，不再自动打开该订阅的编辑弹窗。列表页面的普通查询仍会随导航取消，取消不显示请求失败提示。

订阅创建成功后，当前可见的订阅列表立即重新查询。若列表查询尚未结束，会在它完成后补查，避免旧快照遗漏新订阅；隐藏列表在再次进入时刷新。首次打开列表时，订阅查询与排序配置并行加载。

## 分享详情参数

点击订阅分享卡片后，详情展示分享者设置的关键词、包含、排除、质量、分辨率和特效。未设置或仅有空白的项不显示；包含和排除中的正则表达式原样展示，长文本自动换行，详情内容可滚动查看。自定义识别词继续通过折叠区域查看。

这些字段只用于查看，不会修改分享数据或复用订阅时提交的参数。
